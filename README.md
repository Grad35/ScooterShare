# ScooterShare — аренда электросамокатов

Проект на C# / Windows Forms / .NET 8 / Entity Framework Core / SQLite.

## Возможности
- Регистрация и вход по email и паролю (пароль хранится в виде PBKDF2-хеша).
- Список из 10 самокатов: номер, модель, заряд, место и статус.
- Два тарифа с ценой разблокировки и поминутной стоимостью.
- Начало поездки с проверкой баланса, заряда и доступности самоката.
- Защита от одновременного бронирования одного самоката транзакцией БД.
- Завершение поездки, расчёт стоимости и списание с баланса в одной транзакции.
- История поездок, история операций кошелька и сводный отчёт.
- SQLite-файл `scootershare.db` создаётся автоматически при первом запуске.
- При первом запуске добавляются 5 пользователей, 10 самокатов и 100 демонстрационных завершённых поездок.

## Требования
- Windows 10/11
- Visual Studio 2022 с workload **Разработка классических приложений .NET**
- .NET 8 SDK

## Запуск в Visual Studio
1. Распакуйте архив в отдельную папку.
2. Откройте `ScooterShare.csproj` в Visual Studio 2022.
3. Дождитесь восстановления NuGet-пакетов.
4. Нажмите `F5` или **Запуск без отладки**.
5. База `scootershare.db` создастся рядом с исполняемым приложением.

Можно открыть папку проекта в Visual Studio Code, но для сборки потребуется установленный .NET 8 SDK и расширение C# Dev Kit. В терминале из папки проекта:
```powershell
dotnet restore
dotnet run
```

## Как устроен проект
- `Models/Entities.cs` — сущности пользователей, самокатов, тарифов, поездок и операций.
- `Data/AppDbContext.cs` — схема и связи SQLite через EF Core.
- `Data/SeedData.cs` — заполнение начальными демонстрационными данными.
- `Services/PasswordService.cs` — хеширование паролей.
- `Services/RideService.cs` — бизнес-логика и транзакции.
- `UI/AuthForm.cs` — регистрация и авторизация.
- `UI/MainForm.cs` — вкладки интерфейса.

## Важные замечания
- Пополнение кошелька демонстрационное: интеграции с банком/эквайрингом нет.
- GPS, QR-сканирование, удалённая блокировка и телеметрия самокатов не реализованы.
- Отчёты доступны в учебном интерфейсе всем вошедшим пользователям; в реальной системе их следует ограничить ролью администратора.
- Для учебного проекта используется `EnsureCreated()`. Если схема будет изменяться в ходе разработки, следует перейти на EF Core Migrations.
- SQLite и транзакции обеспечивают атомарность основных операций; для промышленной эксплуатации понадобятся журналирование, серверная авторизация, API и более строгая обработка конкуренции.
